# Flutter Calculator Roadmap

This roadmap outlines the past, current, and future developmental milestones. This project aims to evolve into the ultimate cross-platform, client-side computational utility.

### ✅ Phase 1: The Foundation
- [x] Basic arithmetic operations (addition, subtraction, multiplication, division).
- [x] Simple history and tape view.
- [x] Responsive layout for vertical and horizontal form factors.
- [x] Local state management architecture.

### ✅ Phase 2: Scientific & Pro Tools
- [x] Trigonometry, Exponentials, and Logarithms.
- [x] Smart string parsing parser / AST (`ExpressionEvaluator`).
- [x] Parenthesis balancing and formatted display.
- [x] `flutter_riverpod` state integration.

### 🟡 Phase 3: Advanced Mathematical Workbenches (Current Phase)
- [x] **Matrix Workstation**: Solves determinants, inversions, additions/multiplications, and Eigen computational algorithms locally. fast-entry UI implemented.
- [x] **Equation Workstation**: Systems of linear equations solver (Gauss-Jordan) and generic polynomial root approximations.
- [x] **Graphing Workspace**: Custom interactive viewers handling symbolic equations, generating asymptotes accurately via threshold limit algorithms.
- [x] **Conic Explorer**: Classifications and drawing logic given standard general form combinations mapping circles, hyperbolas, and parabolas. 
- [ ] **Calculus UI**: UI linking to the currently formed numerical differentiation/integration algorithms.
- [ ] **Linear Programming (LPP)**: Graphical and Simplex method maximization/minimization workstations.

### 🔵 Phase 4: Long Term Vision
- [ ] **3D Rendering**: Plotting 3D multivariable surfaces.
- [ ] **Statistics**: Advanced dataset analytics (Regression lines, probability distributions).
- [ ] **Custom Themes**: Complete user customization capabilities across color palettes.
- [ ] **Localization**: Translations for broader accessibility across multiple languages natively.
