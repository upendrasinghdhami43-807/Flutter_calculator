# Security Policy

## Supported Versions

Currently, only the `main` branch of validation is supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| v3.x.x  | :white_check_mark: |
| v2.x.x  | :x:                |
| v1.x.x  | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within this repository, please do not disclose it in a public issue. 

Instead, please send a direct message through GitHub or contact us via email if provided on the profile. 

We will strive to acknowledge your report as fast as possible, verify the vulnerability, and implement the necessary patches in a timely manner. Thank you for helping keep this project secure!
