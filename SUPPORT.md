# Support

Need help using the Flutter Calculator or dealing with an issue?

## 1. Documentation
Start by taking a look at the code comments and our [README.md](README.md). Since this is a mathematics application, our core files within `/lib/core` are heavily commented to explain the mathematical algorithms executing under the hood (e.g. Durand-Kerner polynomials, iterative Eigen algorithms).

## 2. Issues
If you found a bug or have a distinct feature request, please [create an issue](https://github.com/upendrasinghdhami43-807/Flutter_calculator/issues) on GitHub.

When filing an issue, please try to:
- Explain what you were trying to calculate or perform.
- Provide the exact input so we can recreate it.
- Include the device/OS you are running it on (e.g., Linux, Android, iOS).

## 3. Discussions
If you have general questions about how the math engine works, Riverpod state integration questions, or want to discuss adding completely new domains (like Physics or Chemistry constants), start a discussion in the GitHub repository or reach out directly!
